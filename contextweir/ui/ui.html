Something not working?

Problems show a code such as CW-PORT-TAKEN; Help explains each one. To ask someone for help, save a diagnostic report and attach it: it holds versions, settings and recent problems, never your prompts or replies, and nothing is sent anywhere.

ContextWeir forwards only to a model server on this computer. Cloud models (OpenRouter, Claude, OpenAI and the like) are not supported.

Send your chats to another computer?

    
ContextWeir is set to forward everything to . Before you go on:

    
    
      
  • Every prompt and reply crosses the network: your full chats, character cards and lorebook text.
    • 
      
  • This address is plain http: anyone on the network path can read it.
    • 
      
  • The other computer, and whoever runs it, sees everything you send.
    • 
      
  • A mistyped address could send your chats to a stranger's machine. Check it above.
    • 
      
  • ContextWeir never saves your API key, but it passes it on to this address with every request.
